# 💼 個人線上履歷與作品集 (Interactive Resume)

> 兼具簡約視覺設計與流暢互動體驗的個人履歷網頁，展示前端開發與設計作品。

🔗 **線上預覽 (Live Demo)**: [點此查看我的線上履歷](https://你的github帳號.github.io/myresume/) *(若尚未部署可先留空或之後補上)*

---

## ✨ 專案亮點與特色

- **純原生打造 (Vanilla Web)**：不依賴任何重型框架，純以 HTML5、CSS3 與原生 JavaScript 實作，載入速度極快。
- **響應式網頁設計 (RWD)**：支援桌機、平板與手機等多元裝置螢幕體驗。
- **豐富的微互動視覺**：
  - Canvas 動態粒子背景效果
  - 滾動監聽（Intersection Observer）自動觸發區塊進場動畫
  - 導覽列當前區塊自動高亮與流暢平滑滾動

---

## 🛠️ 使用技術

- **結構 (HTML5)**：語意化標籤架構、SEO 友善
- **樣式 (CSS3)**：Flexbox、CSS Grid、自訂動畫與響應式斷點
- **互動 (JavaScript)**：DOM 事件監聽、Canvas 動態渲染、Intersection Observer API
